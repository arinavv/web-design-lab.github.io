Какими свойствами задаются количество и ширина столбцов в Grid-контейнере?

Основные свойства:

  • grid-template-columns — определяет количество и ширину столбцов
  • grid-template-rows — определяет количество и высоту строк

Примеры значений:

.container {
  grid-template-columns: 200px 1fr 300px; /* 3 столбца */
  grid-template-columns: repeat(4, 1fr); /* 4 равных столбца */
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
}

Какой метод можно использовать, чтобы равномерно распределить доступное пространство между столбцами или строками?

Используйте единицу измерения fr (fraction):

  • 1fr — одна доля доступного пространства
  • 2fr 1fr — второй столбец в 2 раза шире первого

Пример:

.container {
  grid-template-columns: 1fr 2fr 1fr; /* средний в 2 раза шире */
  grid-template-rows: 1fr 1fr; /* равные строки */
}

Какие функции CSS Grid позволяют автоматически подстраивать количество колонок или строк под размер экрана?

3 ключевые функции:

  • repeat() — повторение шаблона
  • minmax(min, max) — диапазон размеров
  • auto-fit / auto-fill — автоматическое заполнение

Пример адаптивной сетки:

.container {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
  gap: 20px;
}

Разница:

  • auto-fit — растягивает элементы на всё пространство
  • auto-fill — сохраняет пустые треки

Каким свойством можно задать промежутки между элементами Grid?

Свойство gap (ранее grid-gap):

  • gap: 20px; — одинаковые промежутки между строками и столбцами
  • row-gap: 15px; — только между строками
  • column-gap: 10px; — только между столбцами
  • gap: 20px 10px; — первое значение для строк, второе для столбцов
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px; /* заменяет grid-gap */
}

/* Для поддержки старых браузеров */
.container {
  grid-gap: 20px; /* устаревшее */
}

Как разместить элемент в нескольких строках или столбцах Grid?

Свойства для размещения элементов:

  • grid-column-start / grid-column-end
  • grid-row-start / grid-row-end
  • Короткая запись: grid-column: 1 / 3; (с 1 по 3 столбец)
  • Ещё короче: grid-column: span 2; (занять 2 столбца)
.item {
  /* Занимает 2 столбца и 3 строки */
  grid-column: 1 / 3;
  grid-row: 1 / 4;
}

/* Альтернативная запись */
.item {
  grid-area: 1 / 1 / 4 / 3; /* row-start / col-start / row-end / col-end */
}

Найдите в сети красивое применение Grid

Красивые примеры использования CSS Grid:

  • Галереи изображений с разными размерами (masonry layout)
  • Сетки для журналов/блогов с асимметричными блоками
  • Интерактивные дашборды с перетаскиваемыми виджетами
  • Карточки товаров с адаптивным расположением
