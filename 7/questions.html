Как проверить, является ли число целым?

Основные способы:

// Способ 1: Number.isInteger() Number.isInteger(42); // true Number.isInteger(3.14); // false // Способ 2: Остаток от деления function isInteger(num) { return num % 1 === 0; } // Способ 3: Math.floor() function isInteger2(num) { return Math.floor(num) === num; }

Рекомендация: Использовать Number.isInteger() — это современный и надежный способ.

Как извлечь подстроку из строки?

Методы для извлечения подстроки:

const str = "JavaScript"; // substring(start, end) - от start до end str.substring(0, 4); // "Java" // slice(start, end) - аналогично, но поддерживает отрицательные индексы str.slice(4); // "Script" str.slice(-6); // "Script" // substr(start, length) - от start заданной длины (устарел) str.substr(4, 6); // "Script"

Пример функции:

function getSubstring(str, start, length) { return str.substring(start, start + length); }

Что такое операция "исключающее ИЛИ" (XOR)?

XOR возвращает true если операнды разные, и false если одинаковые.

// Таблица истинности: // true XOR true = false // true XOR false = true // false XOR true = true // false XOR false = false // Реализации: function xor(a, b) { return a !== b; // Самый простой способ } function xor2(a, b) { return (a || b) && !(a && b); // Через логические операторы } function xor3(a, b) { return Boolean(a ^ b); // Через побитовый XOR }

Как проверить наличие свойства в объекте?

Основные способы:

const obj = { name: "John", age: 30 }; // 1. Оператор in (проверяет и унаследованные свойства) 'name' in obj; // true 'toString' in obj; // true (унаследовано) // 2. hasOwnProperty() (только собственные свойства) obj.hasOwnProperty('name'); // true obj.hasOwnProperty('toString'); // false // 3. Сравнение с undefined (не работает для undefined значений) obj.name !== undefined; // true obj.city !== undefined; // false

Разница: in проверяет все свойства (включая унаследованные), hasOwnProperty() — только собственные.

Чем отличаются forEach и map?

Основные различия:

const numbers = [1, 2, 3]; // forEach - выполняет операцию для каждого элемента // НЕ возвращает новый массив const result1 = numbers.forEach(n => console.log(n)); // undefined // map - возвращает новый массив с результатами const result2 = numbers.map(n => n * 2); // [2, 4, 6]

Когда использовать:

  • forEach — для побочных эффектов (логирование, изменение DOM)
  • map — для преобразования данных и цепочек методов
