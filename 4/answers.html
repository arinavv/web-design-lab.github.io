1. Какие типы селекторов CSS существуют, и в чем отличие между селектором класса и идентификатора?

Основные типы: элемента, класса (.class), идентификатора (#id), универсальный (*), атрибутный ([attr]), потомков (пробел), дочерний (>), соседний (+), общий сосед (~), псевдоклассы (:), псевдоэлементы (::).

Отличие class от id:

  • Класс можно использовать много раз на странице, id должен быть уникальным
  • В CSS: .classname и #idname
  • ID имеет более высокий приоритет (специфичность)
  • Классы для стилизации групп элементов, ID для уникальных элементов

2. Как работает универсальный селектор (*), и в каких случаях его использование может быть полезно?

Универсальный селектор (*) выбирает ВСЕ элементы на странице.

Полезные случаи:

  • Сброс стандартных стилей браузера (margin, padding)
  • Наследование свойств для всех элементов
  • Задание box-sizing: border-box глобально
  • Отладка (добавление outline или border)

Пример: * { margin: 0; padding: 0; box-sizing: border-box; }

3. Что такое псевдоклассы и псевдоэлементы? Приведите примеры их использования.

Псевдоклассы — состояния элементов:

  • :hover — при наведении
  • :focus — при фокусе
  • :nth-child(n) — выбор по номеру
  • :first-child — первый элемент

Псевдоэлементы — части элементов:

  • ::before — контент перед элементом
  • ::after — контент после элемента
  • ::first-letter — первая буква
  • ::selection — выделенный текст

Пример: a:hover { color: red; } p::first-letter { font-size: 2em; }

4. Как с помощью атрибутного селектора применить стили к элементам с определенным значением атрибута? Приведите пример.

Синтаксис атрибутных селекторов:

  • [type] — все элементы с атрибутом type
  • [type="text"] — точное совпадение
  • [href^="https"] — начинается с https
  • [src$=".jpg"] — заканчивается на .jpg
  • [title*="logo"] — содержит "logo"

Примеры:

input[type="email"] { border-color: blue; }
a[target="_blank"]::after { content: " ↗"; }
img[alt*="icon"] { width: 32px; }

5. В чем заключается разница между селектором потомков и селектором соседей? Как они применяются на практике?

Селектор потомков (пробел): Выбирает все элементы внутри родителя на любом уровне вложенности.

Пример: nav a — все ссылки внутри nav

Селектор соседей (+): Выбирает только первый элемент, который идет сразу после другого.

Пример: h1 + p — первый параграф сразу после h1

Применение:

  • Потомки: для стилизации всех элементов внутри контейнера
  • Соседи: для специального оформления элементов, следующих за определенными

Примеры:

/* Потомки */
.menu li { display: inline; } /* Все li в меню */

/* Соседи */
.title + p { font-weight: bold; } /* Первый p после .title */
