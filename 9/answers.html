Асинхронность в JavaScript

← На главную

1. Что такое асинхронность?

Асинхронность — это выполнение кода без ожидания завершения долгих операций, например загрузки данных с сервера.

2. Какой объект используется для асинхронных операций?

Используется объект Promise, который может быть в состояниях ожидания, выполнения или ошибки.

3. Чем async/await лучше than .then()?

async/await делает код более читаемым и похожим на обычный синхронный код, упрощает обработку ошибок.

4. Как обрабатываются ошибки?

С помощью конструкции try / catch, которая позволяет перехватывать ошибки в асинхронном коде.

5. Что такое Event Loop?

Event Loop — это механизм, который управляет выполнением асинхронных задач и не даёт JavaScript «зависнуть».
