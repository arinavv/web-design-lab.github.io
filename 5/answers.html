Какие значения может принимать свойство position и как они влияют на положение элемента?

5 значений position:

  • static (по умолчанию) — элемент в потоке документа
  • relative — смещается относительно своего обычного положения (top, left работают)
  • absolute — вырывается из потока, позиционируется относительно ближайшего positioned предка
  • fixed — фиксируется относительно окна браузера (не скроллится)
  • sticky — гибрид relative и fixed (прилипает при скролле)

Разница между display: block, inline, inline-block и none

  • block — занимает всю ширину, начинается с новой строки (div, p, h1)
  • inline — только необходимую ширину, в строке (span, a, strong)
  • inline-block — как inline, но можно задавать ширину/высоту и padding/margin
  • none — элемент полностью скрыт, не занимает место

Пример:

button { display: inline-block; }
nav li { display: inline; }
.popup { display: none; } /* показывается через JS */

Блочная модель CSS и основные свойства

Блочная модель состоит из:

  • Содержимое (content) — ширина/высота
  • Внутренние отступы (padding)
  • Граница (border)
  • Внешние отступы (margin)

Формула: element width = width + padding + border

box-sizing:

  • content-box (по умолчанию) — padding/border добавляются к width
  • border-box — padding/border включены в width
div {
    width: 200px;
    padding: 20px;
    border: 5px solid black;
    margin: 10px;
    box-sizing: border-box; /* общая ширина = 200px */
}

Как работает flex-direction в flex-контейнере?

flex-direction определяет направление основной оси:

  • row (по умолчанию) — слева направо
  • row-reverse — справа налево
  • column — сверху вниз
  • column-reverse — снизу вверх

Управление расположением в flex-контейнере (align-items и justify-content)

justify-content — выравнивание по основной оси:

  • flex-start, flex-end, center
  • space-between — равномерно, без отступов по краям
  • space-around — равномерно, с отступами по краям
  • space-evenly — равномерно, включая края

align-items — выравнивание по поперечной оси:

  • stretch (по умолчанию) — растягивает
  • flex-start, flex-end, center
  • baseline — по базовой линии текста
.container {
    display: flex;
    justify-content: center;    /* по горизонтали */
    align-items: center;        /* по вертикали */
    height: 300px;
}

Красивое применение flexbox

Примеры красивых применений flexbox:

  • Центрирование — вертикальное и горизонтальное выравнивание
  • Адаптивные навигационные меню
  • Карточки товаров одинаковой высоты
  • Стики-футер (прижатый к низу)
  • Сложные сетки с разными размерами элементов

Пример красивой галереи:

.gallery {
    display: flex;
    flex-wrap: wrap;
    gap: 20px;
    justify-content: center;
}
.photo-card {
    flex: 1 1 300px;
    max-width: 400px;
}
